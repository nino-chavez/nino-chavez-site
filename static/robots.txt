# robots.txt for ninochavez.co
#
# THIS FILE GOVERNS THE WHOLE DOMAIN, NOT JUST THIS APP.
#
# Three Cloudflare Pages projects are stitched into one hostname by the router
# worker (apps/router). `/robots.txt` is not claimed by any prefix there, so it
# falls through to this app — which makes this the only robots.txt a crawler
# reads for ninochavez.co. The blog and gallery each ship one too; nothing
# fetches them. Every rule and every Sitemap: line below has to be true for
# paths served by all three apps.
#
# EVERY PATH NAMED HERE MUST RESOLVE. Verify before editing:
#   curl -so /dev/null -w '%{http_code} %{redirect_url}\n' https://ninochavez.co<path>
#
# The previous version of this file failed that check on every line it added:
# it disallowed /case-studies/, /writing/implementations/, /projects/ and
# /api/projects.json — four paths that have never existed on this domain — and
# allowed /cv, which 301s. The case studies it claimed to protect are served at
# /work/<slug> and were allowed to every crawler the whole time. The policy was
# decorative. It is written to match the site now.

# ---------------------------------------------------------------------------
# Default: everything is public.
#
# This is a portfolio. The work being found — by a search engine, by a person,
# or by a model answering a question about it — is the point. /ai/work exists
# to make shipped work discoverable, so blocking crawlers from /work would
# argue against the site's own purpose. Nothing here is proprietary; client
# engagements are described, never documented.
# ---------------------------------------------------------------------------
User-agent: *
Allow: /

# ---------------------------------------------------------------------------
# Common Crawl is the one exception.
#
# Its corpus is redistributed in bulk to anyone, so the machine-readable entity
# files are held back from it — they exist for answer engines that cite a
# source, not for bulk re-hosting. person.json stays allowed so basic identity
# resolution still works; the longer, more specific Allow wins over the
# Disallow under the standard's longest-match rule.
# ---------------------------------------------------------------------------
User-agent: CCBot
Allow: /api/person.json
Disallow: /api/
Crawl-delay: 10

# ---------------------------------------------------------------------------
# Unlisted pages.
#
# Committed as "unlisted" (f9b9bb1) and linked from nowhere, but a URL meant to
# be shared is a URL that leaks. These carry <meta name="robots" content=
# "noindex"> and are deliberately NOT disallowed here: a crawler that is
# blocked never fetches the page, so it never reads the noindex — and if the
# URL was already indexed, blocking it prevents the de-index it needs.
# ---------------------------------------------------------------------------

# ---------------------------------------------------------------------------
# Sitemaps — one per app behind this hostname. All three verified reachable.
# ---------------------------------------------------------------------------

# This app: 23 URLs, generated from the project and track data.
Sitemap: https://ninochavez.co/sitemap.xml

# Blog: a sitemap index pointing at /sitemap-0.xml (319 URLs). NOT
# /blog/sitemap.xml — @astrojs/sitemap emits sitemap-index.xml + sitemap-0.xml
# at the origin root, and the router claims both names. /blog/sitemap.xml used
# to be a hand-maintained file frozen in November 2025 that listed 174 URLs on
# the retired blog.ninochavez.co subdomain, all of which 404 under the router.
Sitemap: https://ninochavez.co/sitemap-index.xml

# Gallery: ~20,900 URLs, served under the /photography base path.
Sitemap: https://ninochavez.co/photography/sitemap.xml
