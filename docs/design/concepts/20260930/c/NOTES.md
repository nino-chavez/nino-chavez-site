# Concept C — The contact sheet

The narrow rail keeps Nino visible while the work field gives photographs, products, writing and the study unequal space. Every object has a direct link and a consistent return path through the rail.

The tradeoff is deliberate density. The work field acts like a browsable contact sheet, so it can feel archival. The portrait, plain introduction and repeat links to the active material keep it personal and practical rather than encyclopedic.

Checks run: `node --check design.js`. No server, browser, install, network request or rendered review was run. Shared helper files were used unchanged; no helper issue found during source inspection.
