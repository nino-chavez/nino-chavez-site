# Concept A — In the field

The home is one full-bleed volleyball photograph with the name and navigation held directly over the image. It then opens into three image-led routes: building, writing, and photography. That commits the first impression to a person in the field rather than a split marketing hero.

Object pages change pace: essays use a light, narrow reading surface; albums stay dark and put actual event photographs immediately after compact event identity; products give the object a generous image or intentional type field. The tradeoff is that photography leads before the full product range, so Building is a stable, visible first-level route.

Implemented all nine contract pages in the owned concept folder. Reused shared navigation, product filtering, photo search, gallery viewer, and product selection helpers. Ran `node --check design.js`.
