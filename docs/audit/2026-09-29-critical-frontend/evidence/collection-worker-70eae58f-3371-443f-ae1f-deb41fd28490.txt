## 2. Ranked causes

1. **Confirmed: the live public pages lack emitters.** The saved read-only GET evidence found only the Cloudflare beacon on `/photography` and `/work/blueprint`, with no tracker reference; the tracker asset itself returned 200 ([raw evidence](/Users/nino/Workspace/dev/sites/nino/nino-chavez-site/.worktrees/codex/frontend-refit-20260929/docs/audit/2026-09-29-critical-frontend/evidence/collection-public-surfaces.json:3)). Main and frontend-refit both lack the candidate’s `SiteActivity`, layout mount, and demo markers. This directly explains no cross-site actions.

2. **Source-confirmed, live impact unverified: React initialization can lose its first view.** A React `nino:page-ready` can run before preferences finish. `start()` records the route before `emit()` suppresses it under the temporary default exclusion; after preferences resolve, the same route returns early ([tracker](/Users/nino/Workspace/dev/sites/nino/nino-chavez-photography/.worktrees/codex/site-action-analytics/static/site-activity.js:46), [tracker](/Users/nino/Workspace/dev/sites/nino/nino-chavez-photography/.worktrees/codex/site-action-analytics/static/site-activity.js:95)). Parent should verify with a delayed-preferences browser rehearsal after deployment.

3. **Source-confirmed limitation, not an explanation for a month of absence:** the report excludes the current UTC day until a same-day refresh. A yesterday-only cutoff can move the completed end date back one additional day ([summary SQL](/Users/nino/Workspace/dev/sites/nino/nino-chavez-photography/.worktrees/codex/site-action-analytics/supabase/migrations/20260930005003_analytics_scheduled_site_reports.sql:246)). Parent can read summary status and raw/count presence. This cannot explain empty prior days if emitters had been live.
